A PAGE OF ME — Putri's personal website

FILES
- index.html: website structure and content
- style.css: visual design and responsive layout
- script.js: navigation, reveal animations, and vision-board image modal
- favicon.svg: custom favicon
- assets/putri-main-photo.png: uploaded main photo
- assets/putri-life-vision-board.png: uploaded original vision board

HOW TO PREVIEW
Open index.html in a browser.

HOW TO PUBLISH ON GITHUB PAGES
1. Extract the ZIP.
2. Upload all files and the assets folder to the root of your GitHub repository.
3. In repository Settings > Pages, select your deployment branch and root folder.
4. Save and wait for GitHub Pages to publish.

NOTES
- The playlist section uses a custom visual design and opens the supplied Spotify playlist. The exact track list was not accessible in this build, so no song names or fake playback controls were invented.
- No background instrumental is included because no authorized audio file was supplied.
- Google Fonts are loaded from Google Fonts when internet access is available; fallback fonts are included.

- Snoopy and Marvel visuals are Pinterest pin embeds linked to their original Pins; they need an internet connection. No images have been cropped from Putri's vision board for other sections.
- Food, drink, perfume, cat, flower, city, Disneyland, and movie photographs are loaded from Unsplash, so those images need an internet connection to appear. Snoopy and Marvel visuals are embedded from Pinterest and may also require internet access. The full vision-board image appears only in its own dedicated section.

Latest revision: added the user-provided matching photos for makeup, perfume, cat, lily, Paris, London, Disneyland, Snoopy, Marvel, and romcom favorites. The food/drink section and original website layout are preserved.
