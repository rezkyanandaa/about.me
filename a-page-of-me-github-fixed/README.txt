A PAGE OF ME — Putri

IMPORTANT FOR GITHUB PAGES
This ZIP has index.html directly at the top level (not hidden inside another folder).
When uploading to GitHub, upload the CONTENTS of this ZIP to the repository root:
index.html, style.css, script.js, favicon.svg, assets/

Do NOT upload the ZIP file itself, and do NOT put these files inside another nested folder.
The repository should show index.html beside style.css and script.js.

Then:
1. Open your GitHub repository.
2. Click Add file > Upload files.
3. Drag the files/folder from inside this ZIP into the page.
4. Commit changes.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for the deployment and open the Pages URL.

This is a static HTML/CSS/JavaScript website. Relative asset paths are used.
The website includes assets/putri-main-photo.png and assets/putri-life-vision-board.png.
If you already have a GitHub Pages URL and the page is still blank, check that index.html is at the repository root and that the selected Pages source is /(root).
